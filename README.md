# مخزون | Makhzon

واجهة لوحة تحكم لإدارة مخزون ومبيعات معرض أجهزة كهربائية (RTL بالكامل، عربي).
المشروع حاليًا **واجهة أمامية ببيانات تجريبية**، والصفحات الأخرى قيد البناء.

## المميزات
- **المنتجات والعملاء:** إضافة وتعديل وحذف وبحث
- **المبيعات:** فاتورة بعدة أصناف، تتحقق من المخزون وتخصمه تلقائيًا
- **الفواتير:** عرض التفاصيل وإلغاء الفاتورة مع إرجاع الكميات
- **حركة المخزون:** سجل تلقائي للبيع والإلغاء + تسجيل وارد/منصرف يدويًا
- **لوحة التحكم والتقارير:** أرقام ورسم بياني من البيانات الفعلية، الأرباح والأكثر مبيعًا
- حفظ كل البيانات في `localStorage` + زر لإعادة البيانات التجريبية
- وضع فاتح/داكن، متجاوب، RTL، وإتاحة (aria، تركيز مرئي، skip link)

## التقنيات
HTML · CSS · JavaScript · Bootstrap 5 RTL · Bootstrap Icons · Chart.js 4

## التشغيل
افتح `index.html` في المتصفح (يحتاج اتصال إنترنت لتحميل المكتبات والخط).

## الخطوات الجاية
- Backend حقيقي (Laravel/Node) وقاعدة بيانات بدل `localStorage`
- تسجيل دخول وصلاحيات، وطباعة/تصدير الفواتير
